# 0.10.0 旧版内容与使用说明

适用 Minecraft 1.21.1、NeoForge 21.1.251、Forbidden and Arcanus 2.6.1。以下新增 ID 的命名空间都是 `better_forbidden_arcanus`，全部位于“更好的禁忌与奥秘”创造栏，图标仍为五级祭坛。

## 恢复的物品与方块

| ID 后缀 | 中文名 | 获取与用途 |
| --- | --- | --- |
| `zombie_arm` | 僵尸手臂 | 僵尸基础 0.2% 掉落，抢夺每级增加 0.1 个百分点；主手总攻击伤害 5、攻速 1.7，不消耗耐久 |
| `shiny_zombie_arm` | 闪光僵尸手臂 | 溺尸掉落，概率和能力与普通手臂相同，采用独立旧模型与贴图 |

| `dark_rune` | 暗黑符文 | 普通符文在核心处转化，或开采／熔炼暗黑符文矿石；用于战斧和暗黑符文袋 |
| `runic_tenebris_frame` | 暗黑符文框架 | 四角奥术金锭、四边錾制磨制符文暗黑石、中央暗物质；用一颗暗黑下界之星右键激活 |
| `runic_tenebris_core` | 暗黑符文核心 | 框架激活后得到；右键进行三条材料转化，不消耗额外燃料或精华 |
| `arcane_gold_ingot` | 奥术金锭 | 4 木炭、2 神秘水晶粉、2 洁净粉末、1 金锭，制作框架；与 Deorum 锭不同 |
| `runic_chiseled_polished_darkstone` | 錾制磨制符文暗黑石 | 錾制磨制暗黑石＋符文；用一个神秘水晶右键激活后，阻止 25 格球形范围内的怪物生成 |
| `skull` | 旧头骨 | 四个骨块菱形排列；合成战斧的材料，不是原版骷髅头颅 |

| `dark_rune_bag` | 暗黑符文袋 | 暗黑符文 2×2 合成，或由普通袋转化；无序拆回 4 个暗黑符文 |
| `dark_runestone` | 暗黑符文矿石 | 三种普通符文矿石物品交给核心转化；正确工具开采掉暗黑符文，时运生效，精准采集保留矿石 |

两种手臂都在**主手近战击杀**马或村民时触发转化，分别产生僵尸马／僵尸村民。村民的职业、类型、等级、交易、流言和经验保留；不是右键转化，不影响其他生物。转化遵守 NeoForge 的生物转化事件，其他 Mod 可以拒绝转化。

核心三条链都消耗一个输入、产生一个输出：

- 普通符文 → 暗黑符文。
- 符文袋 → 暗黑符文袋。
- 符文石头、符文深板岩或符文暗黑石的矿石物品 → 暗黑符文矿石。

产物放进背包，背包无位则掉落。框架和核心支持水浸，激活保留水浸状态。符文暗黑石激活状态随世界保存，破坏后撤销，重新放置需重新激活；不会为其作用强制加载区块。暗黑符文矿石不额外自然生成，普通熔炉烧炼需 250 tick，产出 1 个暗黑符文和 1.2 经验。

## 原布局配方

奥术金锭：`CAC / MGM / CAC`，`C` 木炭、`A` 神秘水晶粉、`M` 洁净粉末、`G` 金锭，产出 1 个。

符文战斧：`RDS / DED / EDR`，`R` 普通符文、`D` 暗黑符文、`S` 旧头骨、`E` 埃德木棍。共消耗 2 符文、4 暗黑符文、2 棍、1 旧头骨。

框架：`AXA / XDX / AXA`，`A` 奥术金锭、`X` 錾制磨制符文暗黑石、`D` 暗物质。

## 独立禁忌之书

采用旧版原始界面图集和书本模型，独立于帕秋莉。恢复主页、物品、方块三个分类，左右切换条目、正文分页、滚轮翻页、配方切换和材料悬停提示，按窗口大小缩放。

共 35 个条目，保留旧书全部原有主题，并补充本次物品、天龙武器与罐子生产。旧黑曜石锭条目适配为当前黑曜钢；临时飞行之球、妖精和黄色兰花明确标注未移植。普通配方按当前世界读取，不继续显示已经失效的旧配方；祭坛仪式及右键交互在正文说明。现有帕秋莉指南保留并同步新增内容，用户编辑的书名、基础材料正文和目录删除保留。

## 本次战斗与遗物调整

- 增强遗物的提示框在黄色“增强遗物”处结束，效果仍生效，完整说明在两本书中。
- 待盈新月和绯红之石在罐顶每 100 tick 产生 3 点对应精华，满罐暂停，最后一批只填满剩余容量。
- 天龙剑、权杖对龙额外 +100%，与每件天龙／提尔护甲 +25% **相加**：武器和全套共 3 倍。权杖包含近战、普通能量球和召雷；普通箭不会因命中前手持权杖而获益。
- 天龙箭的基础动能系数为 5，速度 3 格/tick、无暴击和附魔时命中为 15；实际伤害继续受蓄力、飞行速度、暴击、附魔和强化影响。
- 天龙箭龙息初始半径 2.5、增长 0.015625 格/tick、持续 400 tick，伤害在原值上乘 1.25（原 6 点伤害成为 7.5）。保留原伤害频率，不改普通龙息。范围内非玩家生物持续刷新缓慢 II 和虚弱 II 至 100 tick，离开后五秒消退；免疫该效果的生物仍按原版规则处理。

## 贴图编辑

素材位于 `D:\更好的禁忌与奥秘-贴图编辑`，包括原始备份、可编辑资源包、资源路径清单和说明。五种边框是透明 18×18 PNG，中心 16×16 透明，最外一圈 1 像素；用于物品格子，不描边物品本身。

编辑后把“可编辑资源包”复制到实例 `resourcepacks` 并启用；修改的是已启用副本时，按 F3+T 重载。修改 D 盘素材不会自动覆盖项目和游戏。可用 `python scripts/export_editable_textures.py` 再导出；已有 PNG 编辑不会被覆盖。
