## 2026-10-12

### 目标

实现“更好的禁忌与奥秘”0.1.0，供 Minecraft 1.21.1 / NeoForge 21.1.251 / Forbidden and Arcanus 2.6.1 使用，同时建立标准开发和 Git 工作流。

### 功能需求

- 暗黑石与神秘磨制暗黑石添加基础块到装饰变体的单向 1:1 切石配方。
- 不含镀金块、符文矿、两种基座；失魂沙系列沿用原 Mod 配方。
- 蝙蝠翼采用一次 80% 基础掉落判定，成功数量 1，保留抢夺数量奖励。
- 蝙蝠汤以发光浆果或发光地衣替换下界疣。
- 食用汤必定获得夜视 I 90 秒、速度 I 30 秒、发光 I 90 秒；其他食物属性保持原值。
- 交付 JAR、源码、中文构建安装文档、更新日志、Git 教学。

### 验收标准

- 切石机中总计 39 条指定转换，每条只有一个配方、产出 1；新增部分为 36 条。
- 新汤两种材料分别匹配同一 recipe ID，下界疣组合不匹配。
- 实际原版蝙蝠掉落表在固定随机源下 10000 次模拟，成功率接近 80%；抢夺只增加成功分支数量。
- 完整食用汤后效果时长/等级正确；重复食用不累加时间；取消食用和吃其他食品无新增效果。
- 服务端游戏测试通过；客户端加载到主菜单；发行物不包含开发测试 Mod 或第三方 JAR。

### 边界

本阶段只交付本地首版，不创建远程 GitHub 仓库或推送。远程操作需要真实仓库地址。测试使用独立运行目录，不加载原整合包存档。
