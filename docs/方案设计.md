## 2026-10-12

目标：为 Forbidden and Arcanus 2.6.1 开发 Minecraft 1.21.1 / NeoForge 21.1.251 附属 0.1.0。

### 已确定的行为

- 暗黑石与神秘磨制暗黑石采用基础块单向切割变体，全部 1:1；新增 36 条，保留 3 条。
- 排除镀金、符文矿、普通/磁化基座；失魂沙系列沿用原配方。
- 蝙蝠翼先执行一次 80% 判定，成功掉落 1 片并保留原抢夺数量函数。
- 蝙蝠汤以发光浆果/发光地衣替换下界疣，其他材料和产物不变。
- 夜视与发光各 1800 tick，速度 600 tick，等级 I、概率 1；保留其他食物属性。

### 实现分工

| 模块 | 实现 |
| --- | --- |
| 切石配方 | 附属命名空间下的标准 stonecutting JSON |
| 汤合成 | 覆盖原 recipe ID；Ingredient 替代列表 |
| 蝙蝠掉落 | 覆盖原附加掉落表，不新增全局掉落钩子 |
| 食物效果 | Mod 事件总线 ModifyDefaultComponentsEvent，复制 FOOD 的原有非效果字段 |
| 开发验证 | 独立 GameTest source set，服务端真实配方/掉落/食用检查与客户端启动检查 |

所有 Java 代码只依赖 Minecraft/NeoForge API，通过注册 ID 查找原汤；第三方 JAR 只作为 localRuntime，不嵌入发行包。注册对象缺失时给出清楚错误。

### 交付标准

构建成功；实际资源加载后的配方、掉落和效果验证通过；客户端能到达主菜单；发行 JAR 无测试 Mod、第三方 JAR 或缓存；中文安装/构建/Git 文档齐全。

# 0.3.0 补充设计

## 2026-10-13 17:33

- 继续使用 1.21.1、NeoForge 21.1.251、Forbidden and Arcanus 2.6.1；新增 Curios 9.5.1 编译与运行依赖，不内嵌第三方 JAR。
- 通过 Curios 槽位与玩家实体数据文件注册 `relic`，通过 `curios:relic` Tag 限定七种原物品；注册 `ICurioItem` 能力，不替换原物品。重复检查允许 Curios 重建存档过程尚未发布槽位容器的阶段。
- 基本元素使用原生槽位 modifier 扩容，诅咒契约使用原生最大生命 modifier。直接读取遗物容器和活跃状态；9.5.1 的 `findCurios(Predicate, boolean, String)` 第三个参数是缓存键，不是槽位名。
- 提尔猪灵行为使用局部 PiglinAi 钩子；泳速使用玩家临时属性，依据原版水阻与海豚恩惠计算，兼容冲刺、深海探索者和已有海豚恩惠。属性不写入盔甲组件，避免新增物品属性描述。
- 增伤在 NeoForge 伤害输入事件处理，吸血在实际伤害结算后处理并限制到受害者原有生命。采血在原逻辑完成后补足 50%，锻造炉仅对玩家归属的受伤血液使用局部钩子。
- 工匠加成为 20% 临时战斗与护甲属性，挖掘使用 BreakSpeed 事件。卸下撤销；条件状态记录本附属标记，以保留更长或更强的外来药水。
- 新增语言资源覆盖遗物效果与槽位名；提尔盔甲不添加说明。版本为 0.3.0，构建后完成本地提交与版本标签。

API 参考：[Curios 能力注册](https://docs.illusivesoulworks.com/curios/items/curio-creation)、[槽位 modifier](https://docs.illusivesoulworks.com/curios/slots/slot-modifiers)。实际接口以本地 9.5.1 JAR 为准。
