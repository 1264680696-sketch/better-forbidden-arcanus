## 2026-10-12

目标：为 Forbidden and Arcanus 2.6.1 开发 Minecraft 1.21.1 / NeoForge 21.1.251 附属 0.1.0。

### 已确定的行为

- 暗黑石与神秘磨制暗黑石采用基础块单向切割变体，全部 1:1；新增 36 条，保留 3 条。
- 排除镀金、符文矿、普通/磁化基座；失魂沙系列沿用原配方。
- 蝙蝠翼先执行一次 80% 判定，成功掉落 1 片并保留原抢夺数量函数。
- 蝙蝠汤以发光浆果/发光地衣替换下界疣，其他材料和产物不变。
- 夜视与发光各 1800 tick，速度 600 tick，等级 I、概率 1；保留其他食物属性。

### 实现分工

| 模块 | 实现 |
| --- | --- |
| 切石配方 | 附属命名空间下的标准 stonecutting JSON |
| 汤合成 | 覆盖原 recipe ID；Ingredient 替代列表 |
| 蝙蝠掉落 | 覆盖原附加掉落表，不新增全局掉落钩子 |
| 食物效果 | Mod 事件总线 ModifyDefaultComponentsEvent，复制 FOOD 的原有非效果字段 |
| 开发验证 | 独立 GameTest source set，服务端真实配方/掉落/食用检查与客户端启动检查 |

所有 Java 代码只依赖 Minecraft/NeoForge API，通过注册 ID 查找原汤；第三方 JAR 只作为 localRuntime，不嵌入发行包。注册对象缺失时给出清楚错误。

### 交付标准

构建成功；实际资源加载后的配方、掉落和效果验证通过；客户端能到达主菜单；发行 JAR 无测试 Mod、第三方 JAR 或缓存；中文安装/构建/Git 文档齐全。
