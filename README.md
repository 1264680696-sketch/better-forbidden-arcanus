# 更好的禁忌与奥秘

Minecraft 1.21.1 / NeoForge 21.1.251 / Forbidden and Arcanus 2.6.1 附属，版本 0.9.0。

## 帕秋莉指南与编辑器

**神秘水晶 + 书 → 禁忌与奥秘**，无序合成，使用帕秋莉默认棕色书本，也可从独立创造栏获得。

中文正文按“基础知识 → 搭建祭坛 → 一至五级祭坛”展开，实用支线介绍炽炉、遗物、装备修饰、精华设施与附属便利内容。包含 64 个正式条目，覆盖当前版本全部 29 种有效仪式；所有章节均可提前阅读。目录思维导图见 [GUIDE_STRUCTURE.md](docs/GUIDE_STRUCTURE.md)。

祭坛建造前、激活后基座布局、炽炉和方尖碑使用原生三维结构页。点击眼睛按钮、关闭书本后查看世界投影，再右击方块锚定位置；书内提示说明材料与操作。工作台和熔炼使用原生配方页，祭坛仪式分别列出中央材料、基座材料、四种精华和必要增强器。

双击工程根目录的 **打开指南编辑器.bat**，在本地浏览器中编辑分类、条目、页面并预览。保存会直接写回工程，自动备份旧内容；正文支持帕秋莉格式。保存后构建 JAR 才会更新正式游戏内容，也可导出正文资源包快速预览。使用方法、文件路径和官方教程见 [GUIDE_EDITOR.md](docs/GUIDE_EDITOR.md)。

修复遗物属性标题：基本元素、诅咒契约等物品不再显示未翻译的 `curios.modifiers.relic`，改为中文“装备为遗物时：”，属性数值保留。

## 方尖碑与信标飞行

在神秘磨制暗黑石上叠两块腐化神秘水晶块，用洁净粉末转化为原 Mod 的腐化方尖碑。与普通方尖碑一样，下方为镀金錾制磨制暗黑石时工作；每 100 tick／5 秒向 4 格内最近的赫菲斯托斯锻炉提供 1 点经验精华，不消耗材料，遵守锻炉容量。腐化版不同时供给辉光，普通版继续供给辉光。

神秘龙蛋紧贴有效信标顶面时，提供自由飞行。信标须有有效底座、光路畅通并已选择主效果；原有信标效果保留。一级至四级水平范围为 20／30／40／50 格，垂直包围盒沿用原版。可双击跳跃起飞，沿用正常飞行速度。

离开范围、移除龙蛋或信标、信标失效后立即撤销本附属提供的飞行，不附加缓降。多个结构范围重叠时，任一有效来源仍覆盖玩家就可继续飞行；创造、旁观和其他来源的权限保留。底座与光路激活状态遵循原版信标更新判定；仅处理已加载来源，不强制加载区块。神秘龙蛋的紫黑方块通过附属资源引用本体模型修复。

指南内两种方尖碑保留原生多方块预览与世界投影，缩小展示并分离详细正文。埃德木桶本次保持现状。

## 新增盔甲能力与鞘翅复制

天龙神秘盔甲每件增加 25% 对末影龙的伤害，按件数累加，全套增加 100%。适用于近战和玩家归属的弹射物，保留末影龙原有部位伤害规则；对其他目标不加成。

亡骨盔甲每件减少 12.5% 弹射物伤害，按件数累加，全套减少 50%。按弹射物伤害 Tag 判断，覆盖箭、三叉戟等；在原有护甲及附魔减伤后应用，其他伤害不受此额外减伤影响。工作台配方采用骨头和铁锭，全套共消耗各 12 个。两种能力只计对应护甲槽内的部件，卸下立即撤销，不增加盔甲物品描述。

工作台中央放鞘翅，周围 8 格各放普通龙鳞，消耗 8 个龙鳞并产出 1 个全新未附魔的鞘翅。中央原鞘翅返还在合成格，附魔、剩余耐久、自定义名称等保持原样，可继续合成；其他龙鳞变体不能替代。

以上内容均已写入原指南书。此后的玩法修改也须同步更新指南正文。

## 提尔盔甲与遗物

装备任意一件战神提尔盔甲，普通猪灵会按穿戴金装备的规则对待玩家；主动挑衅仍会激怒它们，猪灵蛮兵沿用原规则。每件盔甲增加游泳速度，四件平均分配加成，全套的稳定泳速达到相同条件下海豚的恩惠效果的 1.25 倍；同时获得海豚的恩惠时仍保持这个目标，不再次重复放大。支持冲刺和深海探索者。盔甲物品描述不添加这些效果。

Curios 新增“遗物”栏，初始 1 个槽位，接受原 Mod 的七种增强遗物，同种只允许装备一个。原有锻造炉与炽炉增强器用途保留；只有实际装备在遗物栏中的物品才提供下列效果：

| 遗物 | 装备效果 |
|---|---|
| 神圣契约 | 对亡灵生物伤害 +25%；生命严格低于当前最大生命的 20% 时获得生命恢复 I |
| 诅咒契约 | 最大生命值 -20%；由玩家归属的伤害 +40%，包括近战、箭矢与魔法伤害 |
| 待盈新月 | 有昼夜的维度在夜晚获得夜视、速度 I、跳跃提升 I；每秒额外恢复 2 点玩家辉光，遵守原有储量上限 |
| 基本元素 | 增加 2 个遗物槽位，即总计 3 个；卸下时额外槽的物品返还背包，背包满时由 Curios 掉落在地上 |
| 工匠遗物 | 铁砧等级费用减半并向上取整，折扣后判断 40 级门槛；铁砧损坏概率乘 0.75；锻造台 25% 概率保留模板 |
| 绯红之石 | 按实际造成的生命损失获得 10% 吸血，不计过量伤害；副手试管采血和玩家攻击供给附近锻造炉的血液 +50%，不放大储存血液的转移量 |
| 灵魂绯红之石 | 可装备，暂未增加装备能力 |

不同遗物的伤害倍率相乘：神圣契约与诅咒契约同时装备，对亡灵为 1.25×1.4=1.75 倍。吸血不由被取消、完全格挡或未造成生命损失的攻击触发。移除遗物会撤销其属性与自行给予的状态，不删除更长或更强的外来药水效果。新增能力写入遗物的中英文描述。

## 炽炉与灵魂扩展

炽炉灵魂槽内的灵魂不再被消耗，槽位决定火焰和速度；取出后立即取消加速。普通灵魂为 1.25 倍，腐化灵魂为 1.5 倍，附魔灵魂为 2.5 倍。燃料仍正常消耗。

灵魂槽放入腐化或附魔后，炽炉可将 **1 个灵魂沙加工为 1 个灵魂，并必定生成 1 份失魂沙残留物**。普通灵魂不能启用此配方。残留物沿用原 Mod 的自动合并流程，有输出空间时，每份转换为 1 个失魂沙。基础加工时间为 100 tick，经验产出为 0。输入、燃料、输出或残留物空间不满足条件时停止；取出合格灵魂会清空此配方的进度。

新增两种赫菲斯托斯锻造炉仪式：

| 产物 | 最低等级 | 中央槽 | 四个基座各放一个 | 辉光 | 灵魂精华 | 血 |
|---|---:|---|---|---:|---:|---:|
| 腐化灵魂 ×1 | II | 灵魂 ×1 | 腐化粉末 | 100 | 10 | 250 |
| 附魔灵魂 ×1 | III | 腐化灵魂 ×1 | 附魔之瓶 | 500 | 20 | 500 |

两种仪式均持续 500 tick，经验精华消耗为 0，不要求增强器，更高等级也可使用。

三种永恒灵魂已彻底移除，不转换旧物品。原有三种灵魂只在炽炉槽内不消耗，在精华供给、仪式和植物转化中照常消耗。独立创造栏图标改为五级赫菲斯托斯锻炉，指南仍可从该栏取得。

## 工匠遗物与装备强化

工匠遗物放祭坛增强器槽，待强化装备放中央，八份外围材料各放一个基座，用锻工锤启动 500 tick 仪式。不消耗工匠遗物或精华；每座祭坛只执行自身等级的强化。

| 等级 | 加成与颜色 | 材料 |
|---|---|---|
| I | 5%，白 | 铁锭×4、铜锭×2、神秘水晶×2 |
| II | 10%，绿 | Deorum 锭×4、钻石×2、神秘水晶块×2 |
| III | 20%，蓝 | 黑曜钢锭×4、龙鳞×2、下界合金锭×2 |
| IV | 30%，紫 | 下界合金锭×4、暗黑下界之星×2、星辰碎片×2 |
| V | 40%，红 | 下界合金块×2、星辰块×2、暗黑下界之星×2、永恒之石×2 |

未强化或低级装备可支付目标等级完整材料直接提升，新等级替换旧等级。禁止同级和降级；取消仪式保留未消耗材料。保留附魔、耐久损耗、名称、纹饰及其他组件，不修复耐久。

支持常规工具、近战武器、盔甲以及标准弓弩。工具与近战武器提升攻击伤害、实际攻速和挖掘速度；盔甲提升自身护甲、韧性和抗击退，零值保持零。弓弩提升蓄力速度、初速度与伤害，兼容快速装填及烟花；箭矢补偿速度增伤，避免强化倍率重复乘算。发射时记录倍率，换武器不改变已发射弹射物。盾牌、鞘翅和完全自定义发射器不适用。

工具绿色属性行直接显示强化后的伤害和攻击速度，不另列强化增量或等级说明文字。等级组件随物品保存和同步。背包、快捷栏、容器中的物品格显示一像素彩色边框，名称使用对应颜色，不修改贴图；标准修理和锻造保留等级。装备工匠遗物本身不再直接提升工具或盔甲属性。

恢复天龙工具的默认攻击属性：剑 12/1.8，镐 10/1.4，斧 14/1.2，锹 10.5/1.2，锄 4/5（伤害/速度）；权杖显示其原有近战 1/4，能量球规则保留。

恢复天龙剑、镐、斧、锹、锄、杖柄、权杖七种原版旧配方，来源为官方 GitHub `1.20.x` 提交 `189c3ca`；旧黑曜石锭替换为黑曜钢锭。盔甲仍通过已有祭坛仪式取得。

黑曜石头骨的合成、着火退化和黑曜钢修复路径已写入指南。2.6.1 的辉光、永恒变体无默认生存获取途径，头骨盾未注册，本版不增加其配方。

## 粉末与水晶转化

洁净粉末配方改为神秘水晶粉、红石、骨粉、火药、金锭各一份，无序合成产出 4 份。用腐化粉末右击已放置的神秘水晶块，每次消耗一份并转化为腐化神秘水晶块，迸出水晶粒子，播放方尖碑转化声音；创造模式不消耗。

## 安装

客户端和服务端都安装此附属，并准备：

- Minecraft 1.21.1。
- NeoForge 21.1.251。
- Forbidden and Arcanus 2.6.1。
- 原 Mod 的必需依赖 Valhelsia Core；本项目测试使用 1.1.5。
- Curios API，开发版本为 `9.5.1+1.21.1`（本版必需依赖）。
- Patchouli（帕秋莉手册）`1.21.1-93-NEOFORGE`，客户端与服务端均需安装。

将 `build/libs/better_forbidden_arcanus-0.9.0.jar` 放入游戏实例的 `mods` 目录。升级时只保留一个版本的附属 JAR；不要移除原 Mod 或 Curios。若启用了旧版编辑器导出的指南资源包，请关闭或重新导出，以免旧正文覆盖新版。

## 从源码构建

在项目目录中打开 PowerShell：

```powershell
# 首次运行或从旧版升级：从当前实例复制开发依赖到 libs。
.\scripts\setup-dev.ps1

# 开发脚本使用 JDK 21，并将 Gradle 缓存放在项目内。
.\scripts\dev.ps1 build
.\scripts\dev.ps1 runGameTestServer
.\scripts\dev.ps1 runClientSmoke
.\scripts\dev.ps1 runClientGuide
.\scripts\dev.ps1 runClient
```

脚本默认 JDK 路径为 `C:\Program Files\Java\jdk-21`。其他电脑可设置 `$env:BFA_JDK_HOME`；也可以使用 JDK 21 直接运行官方 `gradlew.bat`。需要能够访问 Gradle、NeoForge 和 Mojang 下载服务。

开发脚本会在当前进程中采用已启用的 Windows HTTP 代理，并使用实例中的 `.bfa-tmp` 短临时目录以避免 Java Windows 套接字路径限制；不会修改系统代理设置。

`runClient`、`runServer` 和自动测试使用项目 `runs/` 下的独立目录，不读取整合包的存档。第三方依赖只用于开发运行，不打包进附属。

首次下载 Minecraft 编译环境可能耗时较长。用支持 Gradle 的 Java IDE 打开项目根目录，即可查看源码和运行配置。

## 文件怎么分工

- `src/main/java`：Mod 入口、物品与创造栏注册、蝙蝠汤组件，以及限定目标的 Mixin。
- `RelicCurio`／`RelicEffects`／`TyrArmor`／`TyrCombat`：原物品 Curios 接入、遗物效果和提尔盔甲行为。
- `src/main/resources/data/better_forbidden_arcanus`：新增切石／炽炉配方、灵魂 Tag、仪式和残留物类型。
- `src/main/resources/data/forbidden_arcanus`：覆盖汤配方、蝙蝠翼掉落表、灵魂绑定仪式，以及追加炽炉灵魂 Tag。
- `src/main/resources/assets/better_forbidden_arcanus`：物品模型、动画贴图和中英文名称。
- `data/better_forbidden_arcanus/curios` 与 `data/curios/tags/item/relic.json`：玩家遗物槽与可装备物品清单。
- `src/gametest`：独立测试 Mod；不进入发行 JAR。
- `scripts/generate_resources.py`：生成配方与掉落资源。
- `scripts/verify_resources.py`：与原 JAR 对照检查配方、范围、重复和掉落规则。
- `scripts/verify_guide.py`：核对指南的等级归类、仪式覆盖、精华消耗、条目跳转、原生配方类型与结构用量。使用 Python 3 直接运行。
- `runClientGuide`：在独立临时世界检查真实书页排版、三维渲染与五种世界投影；不读取整合包存档。

## 提尔套装新能力与疾风重锤（0.9.0）

英勇（至少一件）：每种负面状态+10%，16格内每个敌人+5%，两部分各上限50%且乘算，最高2.25倍。影响伤害、攻速、地面移速、护甲与韧性，零值不变；敌人包括敌对怪物和正在攻击你的中立生物，不包括友方、宠物和玩家。公正（至少两件）只改变伤害，倍率为1+clamp(目标最大生命值/自身最大生命值-1,-0.5,0.5)。近战和玩家归属远程均按命中时条件计算，与既有倍率相乘。

全套新增60%弹射物减伤及盾牌禁用；手中盾牌移入背包，背包无位则掉落。普通致命伤害计入吸收后保留1点生命，播放不死图腾音效，获得首个实际造成生命伤害命中的五倍反击；不额外治疗、净化或增加无敌时间。虚空与绕过无敌的伤害不触发。保命冷却2400游戏tick，跨维度、重登和死亡重生不重置；脱掉全套或死亡清除待反击。

模板+重锤+旋风棱晶可在锻造台产出疾风重锤，沿用单修饰与工匠遗物模板保留规则，保留原组件。右键地面上表面将使用者向上弹起约8格，保留水平速度，不耗耐久、同一玩家共享20tick冷却；风弹落地高度规则和重锤下落攻击保留。旋风放置模型由附属补齐。上述能力只写入指南，不增加盔甲描述或状态图标。
