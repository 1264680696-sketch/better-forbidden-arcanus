使用说明与游戏预览

从书中的目录进入章节、条目，点击标题和正文即可编辑。书内的“＋”可以新建内容。物品图标可点击后按中文名搜索。高级设置中仍可移动章节、调整排序或编辑原始 JSON。

导出预览包仅包含已保存的目录与正文。将 ZIP 放入游戏 resourcepacks 并启用；已有指南可重载查看。书名、封面简介等指南设置及合成配方需重新构建 JAR。

内容超过游戏页面高度时会提示拆页。物品与配方 ID 可从游戏高级提示或 JEI 查看。
