第一本指南

排版为近似预览。游戏内的字体、分页和物品模型以帕秋莉实际显示为准。

怎么编辑与在游戏中查看？

选分类或条目 → 编辑标题和页面 → 保存到工程。正文支持帕秋莉格式；原始 JSON 可编辑更多页面类型，未知字段会保留。

导出预览包仅包含已保存的目录与正文。将 ZIP 放入游戏 resourcepacks 并启用；已有指南可重载查看。书名、封面简介等指南设置及合成配方需重新构建 JAR。

未找到物品图标时显示文字标识。物品与配方 ID 可从游戏高级提示或 JEI 查看。
